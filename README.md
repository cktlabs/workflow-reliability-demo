# Один заказ. Одна операция. Даже после сбоя.

**Запускаемый инженерный пример CKT Labs:** как обработать повторный запрос, перезапуск программы и временную недоступность внешнего сервиса.

Для бизнеса это вопрос прост: что произойдёт с заказом, если система не получит ответ или сотрудник нажмёт кнопку дважды?

![Результаты трёх выполненных сценариев](assets/report.svg)

**Синтетические заказы и имитатор платёжного провайдера.** Пример работает локально, без реальных платежей, аккаунтов и сетевых запросов.

## Что проверяется

| Ситуация | Что делает пример | Полученный результат |
| --- | --- | --- |
| Один и тот же запрос приходит трижды | Узнаёт уже принятый запрос | 1 заказ, 1 операция у имитатора провайдера. |
| Обработчик падает после выполнения внешней операции | После перезапуска повторяет обращение с тем же ключом | Провайдер возвращает существующую операцию. |
| Получатель уведомления временно недоступен | Повторяет доставку, сохраняя идентификатор уведомления | Уведомление принято после восстановления; операция не повторяется. |

Картинка выше построена по выполненному запуску. [Машиночитаемый отчёт](examples/report.json) можно воспроизвести командой ниже.

## Запуск за минуту

Нужен Python 3.11 или новее. Устанавливать дополнительные пакеты не требуется.

```sh
git clone https://github.com/cktlabs/workflow-reliability-demo.git
cd workflow-reliability-demo
python demo.py
python -m unittest -v
```

В `artifacts/` появятся отчёт `report.json` и его визуальная версия `report.svg`. Демонстрация использует временные базы SQLite; повторный запуск создаёт новые сценарии.

## Для технического руководителя

- Заказ и задание на внешнюю операцию сохраняются одной транзакцией.
- Идентификаторы запроса и заказа проверяются вместе с содержимым операции.
- Внешний имитатор хранит собственный журнал и поддерживает идемпотентный вызов.
- Обработчик восстанавливается по сохранённым заданиям; уведомления имеют стабильный идентификатор.
- После исчерпания попыток задание получает состояние `dead`; система не объявляет его успешно выполненным.
